# Counter App Example

A complete Velox application demonstrating:

- **Interactive Components**: Click handlers update component state
- **Event Binding**: @click, @input, @change directives working
- **Advanced Styling**: 
  - Flexbox layouts
  - Box shadows and rounded corners
  - Gradient backgrounds
  - Responsive design
  - Hover effects with transitions
- **Conditional Rendering**: v-if/v-else blocks
- **Data Binding**: {{ count }} interpolation
- **Typography**: Font sizes, weights, line heights

## Getting Started

```bash
cd examples/counter-app
cargo build
cargo run
```

## Features

- Increment/decrement counter
- Custom value input
- Visual feedback (positive/negative/zero states)
- Smooth animations on button hover
- Mobile-responsive design
- Dark mode gradient header

## What This Demonstrates

✓ CSS Properties working correctly (flexbox, colors, shadows, etc.)
✓ Event handlers (@click binding)
✓ Component state management
✓ Template interpolation
✓ Conditional rendering
✓ Responsive layout

This example validates that Phases 1-5 are working and can be built into a complete app.
